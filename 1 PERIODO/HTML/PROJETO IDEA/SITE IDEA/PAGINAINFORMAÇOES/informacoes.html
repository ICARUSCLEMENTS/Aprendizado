O que é um processador?

O processador executa desde tarefas simples, como cálculos básicos, até processos complexos, como renderização de gráficos, cálculos científicos e gerenciamento de sistemas operacionais. Ele funciona em conjunto com outros componentes para garantir o desempenho do dispositivo.

O que é um Placa-mãe?

É a base do computador, onde todos os outros componentes estão conectados. Ela permite a comunicação entre processador, memória RAM, armazenamento, placa de vídeo e outros periféricos.

O que é uma Memória RAM?

Responsável pelo armazenamento temporário de dados enquanto o computador está ligado. Quanto mais RAM, mais rápido o PC pode rodar programas simultaneamente.

O que é uma Placa de Vídeo?

Processo gráfico e imagens, essencial para jogos, edição de vídeo e design 3D. Pode ser integrado à placa-mãe ou dedicado (mais potente).

O que é uma Fonte de Alimentação?

Converta a energia elétrica da tomada para alimentar todos os componentes do PC com a voltagem adequada.
